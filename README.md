# 오늘 밥상 물가

KAMIS 품목 가격을 **메뉴 가격**으로 바꿔 주는 서비스입니다.
"배추 1포기 6,149원" 대신 "김치찌개 1인분 집에서 끓이면 2,251원, 사 먹으면 8,769원"으로 보여 줍니다.

## 메뉴로 보는 밥상 물가

| 화면 | 내용 | 쓰는 데이터 |
| --- | --- | --- |
| 메뉴판 | 집밥 20가지의 오늘 1인분 재료비, 평년 대비 신호, 외식비와의 차이 | KAMIS 일별 소매가 × 레시피 g, 참가격 외식비 |
| 메뉴 상세 | 재료별 원가 막대, 값을 끌어올린 재료, 바꿔 넣으면 얼마, 메뉴 제철 예보, 3년 원가 그래프 | KAMIS 일별 · 기간별 소매가 |
| 김치찌개 지수 | 빅맥 지수처럼 김치찌개 1인분 재료비로 재는 3년 밥상 물가, 메뉴별 3년 변화율 | KAMIS 기간별 소매가 3년치 |
| 김장 | 4인 가족 김장 재료비, 김장 재료가 제일 싼 달, 24개 지역 비교 | KAMIS 지역별 소매가 |
| 냉털 | 냉장고에 있는 재료로 만들 수 있는 메뉴와 모자란 재료값 | 3D 냉장고 + 위 데이터 |

- 레시피는 `src/dishes.js`에 1인분 g으로 적혀 있고, 양념 · 두부처럼 KAMIS가 조사하지 않는 재료는 화면에 "빠진 재료"로 밝힙니다.
- 김치는 배추 · 고춧가루 · 마늘로 환산합니다. 배추와 무는 계절마다 품종 코드(봄 · 고랭지 · 가을 · 월동)가 바뀌어 네 종류를 이어 붙여 씁니다.
- 외식비는 한국소비자원 참가격(행정안전부 지방물가 조사) 시도별 값을 KAMIS 조사 지역에 맞춰 씁니다. 지금 값은 2026-08 기준입니다.
- 월별 메뉴 원가는 `scripts/dish-index.mjs`가 `data/history`로 계산해 `data/dish-index.json`에 둡니다.

## 냉장고

3D 냉장고 안 재료마다 KAMIS 시세 신호등을 달아 줍니다.
재료를 냉장고에 넣으면 그날 시세가 바로 붙고, 냉장고 문을 열면 비싼 재료에는 빨간 ↑, 싼 재료에는 초록 ↓ 표가 뜹니다.

## 무엇을 알려 주나

| 화면 | 내용 | 쓰는 KAMIS 데이터 |
| --- | --- | --- |
| 냉장고 위 신호등 | 재료마다 평년 대비 싸요 / 보통 / 비싸요 | 일별 부류별 도·소매가격 (`dailyPriceByCategoryList`) |
| 내 냉장고 | 비싼 재료는 같은 쓰임새의 지금 싼 재료로 바꿔 보기 | 같은 날 6개 부류 전체 |
| 오늘 시세 | 69개 품목 전체 신호판 | 〃 |
| 단백질 가성비 | 1,000원으로 살 수 있는 단백질(g) 순위 | KAMIS 가격 × 식품성분표 |
| 우리 동네 | 24개 조사 지역 가격 비교 | 지역 코드별 수집 |
| 살 타이밍 예보 | "보통 ○월에 제일 싸요", 최근 1년 중 지금 가격의 위치 | 기간별 소매가격 3년치 (`periodRetailProductList`) |
| 장보기 기록 | 산 날의 시세와 평년을 비교해 얼마나 아꼈는지 누적 | 위 데이터 + 사용자 기록 |

## 신호 기준

- 오늘 가격 ÷ 평년 가격이 0.92 이하면 싸요, 1.08 이상이면 비싸요, 그 사이는 보통입니다.
- 평년 값이 없으면 1년 전 값, 그것도 없으면 1달 전 값과 비교합니다.
- 축산물은 KAMIS가 전국 단일 가격으로 조사하므로 지역을 바꿔도 같습니다.
- 지역 조사값이 없는 품목은 서울 가격을 쓰고 화면에 그렇게 밝힙니다.

## 살 타이밍 예보 계산

1. 3년치 일별 가격을 달마다 평균 냅니다.
2. 각 달 평균을 그 달 앞뒤 12개월 평균으로 나눕니다. 물가 상승분은 빠지고 계절 효과만 남습니다.
3. 같은 달끼리 3년치 비율을 평균 내서 1~12월 지수를 만듭니다. 가장 낮은 달이 제철입니다.
4. 1년 중 최고 달과 최저 달 차이가 8% 미만이면 "철에 따라 값이 거의 안 변해요"라고 안내합니다.
5. 오늘 가격이 최근 365일 가격 중 몇 % 위치인지 함께 보여 줍니다.
6. 평년 기준 신호와 최근 1년 위치가 엇갈리면(예: 평년보다 싸지만 1년 중엔 비싼 편) 그 사정을 따로 풀어 줍니다.

## 데이터 흐름

```
GitHub Actions (매일 20:30 KST)  → scripts/collect.mjs → data/daily/YYYY-MM-DD.json, data/latest.json
GitHub Actions (매주 일요일)     → scripts/history.mjs → data/history/{품목}.json
GitHub Pages                     → index.html 이 data/ 를 읽어 화면에 그림
```

- 인증키는 저장소 비밀값(`KAMIS_CERT_KEY`, `KAMIS_CERT_ID`)으로만 씁니다. 브라우저에는 키가 가지 않습니다.
- 매일 6개 부류 × 24개 지역을 받아 약 3,400행을 저장합니다.

## 출처

- 가격: 한국농수산식품유통공사 KAMIS Open API
- 외식비: 한국소비자원 참가격 외식비 (행정안전부 지방물가 조사, 잠정치)
- 단백질·열량: 농촌진흥청 국가표준식품성분표 기준 근사값. 품목별 가식부 무게(`g`)는 KAMIS 조사 단위를 실제 먹는 부분 무게로 환산한 추정치입니다.

## 직접 돌려 보기

```
npm install
node build.mjs index.html
python -m http.server 8765
```

수집 스크립트는 `kamis.local.json`(`{"cert_key": "...", "cert_id": "..."}`)이나 환경 변수의 키를 씁니다. 둘 다 없으면 KAMIS 테스트 키로 동작합니다.
